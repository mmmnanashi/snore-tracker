# いびきトラッカー

寝ている間の音をスマホのブラウザで録音し、いびきらしい音が出た時間と大きさをグラフにするアプリです。

## 使い方

1. スマホのSafariかChromeで https://mmmnanashi.github.io/snore-tracker/ を開く
2. 充電しながら枕元に置き、月をタップして録音を始める
3. 朝、月を2回続けてタップして録音を止める（記録は自動で保存されます）

## 記録の保存先

録音と記録は、ページを開いたブラウザの中（IndexedDB）にだけ保存されます。サーバーには送信しません。
ブラウザの履歴やサイトデータを消すと、記録も消えます。

## 注意

- 録音中は画面をつけたまま、このページを開いておいてください。
- いびきの判定は音の大きさによる簡単なもので、医療的な診断には使えません。
