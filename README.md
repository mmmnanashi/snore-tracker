# いびきトラッカー

寝ている間の音をスマホのブラウザで録音し、いびきらしい音が出た時間と大きさをグラフにするアプリです。

## 使い方

1. スマホのSafariかChromeで https://mmmnanashi.github.io/snore-tracker/ を開く
2. 充電しながら枕元に置き、月をタップして録音を始める
3. 夜中に起きたときは「一時停止」、また寝るときに「再開する」を押す（同じ夜の記録として続きます）
4. 朝、月を2回続けてタップして録音を止める（記録は自動で保存されます）

## わかること

- いびきの割合・時間・回数、多い時間帯
- いびきの種類：800Hzより上の音がどれくらい含まれるかで「ガー型（高めの音を含むひらいた音。口で息をしているときに多い）」と「ズー型（低くこもった音。鼻で息をしているときに多い）」に分けます。例の音を聞いて確かめられます
- 「寝る前のこと」のチェック項目との関係（分析タブ）

## 画面について

- iPhoneのブラウザは、画面を消すと録音が止まります。録音中は20秒ほどで真っ黒な画面になるので、画面はつけたままにしてください。
- Androidは機種によって、画面を消しても録音が続くことがあります。画面を戻したときに、消していたあいだ録れていたかを表示します。
- 途中でページが止まっても、1分ごとに保存している数値は残ります。

## 記録の保存先

録音と記録は、ページを開いたブラウザの中（IndexedDB）に保存されます。
Googleでログインすると、数値・チェック項目・メモが自分のFirebaseにも保存されます（音声は送りません）。
ブラウザの履歴やサイトデータを消すと、この端末の記録は消えます。

## 注意

- いびきの判定は音による目安で、医療的な診断には使えません。
